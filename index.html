        ⚠️ Maintenance & Repair Tools
        
Not everyday actions — for fixing data that's drifted or gone missing. Everything below is safe to run when genuinely needed, but not something to reach for casually.

      


      

        
Reset season

        
Zeroes every member's stats, dues, and group financials back to a clean slate, and clears saved-week history. Use this if you're going to re-enter the season from Week 1 so the graph and totals build up correctly. Names and bet slips are kept.

        
        

      


      

        
Recalculate balances from history

        
Rebuilds the bank total and every member's stats (wins/losses/legs/P&L) completely from scratch, by re-summing every saved week in history. Use this if a save/undo ever leaves numbers looking off — history is treated as the source of truth, so this fixes drift without touching your saved weeks themselves or dues owed. Safe to run — nothing here changes unless the numbers genuinely didn't match.

        
        

      


      

        
Fix a saved week

        
For correcting an already-saved week's individual bet numbers directly — e.g. if a second bet for the same person that week wasn't captured correctly at the time. Recalculate above only re-sums what's already stored, so it can't fix a week where the wrong number was saved in the first place; this edits the actual saved entry, then automatically recalculates every member's totals from scratch afterward so the fix ripples through correctly.

        
        

        
        

      


      

        
Clear "missing groupEntries" health check warning

        
For weeks where nobody had a group multi leg on purpose (not a data-loss bug) — the health check can't tell "genuinely nothing to record" apart from "field never got saved," so it warns on both. This sets those specific weeks' groupEntries to an empty (but present) record, which is enough to satisfy the check without inventing any leg data — nothing about anyone's stats or the bank changes.
